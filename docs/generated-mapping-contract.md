# Generated mapping contract

`GenerateMapperAttribute` is injected into the consuming compilation by the packaged analyzer. It and `GeneratedMappingMode` are internal to that compilation. Add the attribute to a partial class; nested containing types must also be partial. Methods are public static, and retain the name `MapTo{DestinationSimpleName}` unless `MethodName` is supplied. Separate partial declarations contribute to one mapper file with the existing metadata-based hint name.

## Modes and defaults

| Property | Default |
| --- | --- |
| `Mode` | `GeneratedMappingMode.Legacy` (`0`; `Structural` is `1`) |
| `MaxDepth` | `64` |
| `MaxCollectionItems` | `10000` |
| `PreserveReferences` | `false` |
| `AllowUndefinedEnumValues` | `false` |
| `AllowNullCollections` | `false` |
| `AllowNullDestinationValues` | `true` |
| `GenerateResolver` | `false` |
| `MethodName` | `null` |

`Legacy` preserves existing same-name, same-type assignments, shallow reference/collection aliases, skipped mismatches, and null-source return of `default`. Public readable source properties map to public writable or init destination properties, including inherited properties with most-derived hiding rules. An accessible unambiguous destination constructor callable without arguments must satisfy required members (for example through `SetsRequiredMembers`). Automatic constructor selection is available only in Structural mode. Explicit member attributes below also work in Legacy.

`Structural` opts into checked member coverage for the currently implemented subset: identity scalar assignments, numeric widening, nullable transitions, enums, public constructor binding, and shallow same-type ordinary references when no nested mapping pair is declared. Every eligible destination property without a readable source or a supported conversion is an error; a required member is never silently omitted. Required fields and required properties outside the supported writable surface are rejected. Declared nested mappings and supported collections traverse with enforced depth and item limits. Root null-source handling currently retains the legacy `default` return.

Positive limits are required in both modes. Legacy accepts the semantic option values without changing its documented shallow/null behavior; choose Structural when requesting checked transformations. `GenerateResolver=true` is rejected in either mode until resolver integration is implemented. Structural entry methods also accept an optional second `GeneratedMappingOptions` argument. Runtime registration and resolver integration remain pending; full runtime-profile equivalence is not claimed.

```csharp
[GenerateMapper(typeof(Order), typeof(OrderDto),
    Mode = GeneratedMappingMode.Structural, MethodName = "ToOrderDto")]
public static partial class OrderMaps { }
```

`MethodName` must be a valid non-reserved C# identifier without a verbatim (`@`) prefix or Unicode format characters (which C# ignores for identifier identity), and must be unique among mapping names and members declared in the container. Default names may overload across distinct source types. Collision checks treat `dynamic` and `object` as the same signature type, including nested generic arguments and arrays; escaped spellings of existing member names retain their compiler identity. Two destination types with the same simple name and the same source need distinct explicit names. Duplicate source/destination pairs are an error even with different names. Existing container members and the container's own name cannot be replaced by a generated conflicting method. Source/destination types must be nameable, closed and accessible with visibility sufficient for the emitted public method.

## Constructors and explicit member configuration

Structural mode chooses the public constructor with the largest number of resolvable parameters. Parameters bind to explicitly configured members first, then case-insensitive public readable source properties with assignable identity/reference/boxing types, then optional defaults. A narrower constructor remains eligible when a wider constructor has an unresolved required parameter. Equal best candidates produce `MERIDIANGEN003`; inaccessible constructors and ref/out/in parameter constructors are ineligible. Optional constants are emitted with explicit types and invariant literals, including enum and decimal defaults. No runtime reflection or dynamic invocation is generated.

Records, ordinary immutable DTOs and record structs use constructor arguments plus an object initializer. Constructor-consumed properties are not assigned again when their destination type and source binding match the selected argument. Optional defaults never consume an independently mappable initializer; an unconfigured same-type property with no source may remain satisfied by its matching optional parameter default. Explicit constructor-only requests must all be bound by the selected eligible constructor, so an unrelated or parameterless fallback cannot discard them. As required by C#, required properties must appear in the initializer unless the selected constructor has `SetsRequiredMembers`. Public required/init properties must be mapped; an ignore cannot bypass the language's required-member obligation. Required fields remain unsupported. Plain Legacy continues binding the existing lexical `new Destination()` expression, including its optional/params behavior, and never opts into source-fed constructor selection.

The generator injects four container attributes:

```csharp
[GenerateMapper(typeof(Person), typeof(PersonDto), Mode = GeneratedMappingMode.Structural)]
[MapMember("Name", "DisplayName")]
[MapWith("Age", typeof(MemberConverters), "ConvertAge")]
[IgnoreMapMember("Note")]
public static partial class PersonMaps { }
```

`MapMember(destinationMember, sourceMember)` overrides naming convention. `MapWith(destinationMember, converterType, methodName)` calls one accessible, nongeneric static method with one by-value source-member argument and an assignable return value. The two attributes may compose; otherwise the converter receives the convention-matched source property. Identity, reference and boxing assignability are supported without introducing implicit numeric conversions. Inherited static methods are supported with normal member hiding. Instance, generic, abstract/virtual static interface, inaccessible, incompatible or ambiguous methods produce `MERIDIANGEN006`. A custom method is responsible for the conversion it explicitly implements, including collections or enums; its own traversal and cancellation are the custom method's responsibility. An ignore preserves the destination's constructor/initializer value and suppresses the unmapped-member diagnostic. Conflicting or repeated configuration is invalid.

All four attributes expose optional `SourceType` and `DestinationType` selectors. Both selectors target exactly one declared pair; one selector, null selectors or a nonexistent pair are invalid. Without selectors, configuration applies to every declared pair whose supported destination surface contains that name. Other destination shapes are unaffected. A missing source or invalid converter in an applicable pair is diagnosed; configuration matching no declared pair is invalid. Constructor parameter names use case-insensitive matching; property names and explicit source names use exact matching. Attributes across partial declarations participate in the same container.

These APIs apply in both modes and leave unconfigured Legacy behavior unchanged. Runtime expression/lambda parsing, `ForCtorParam`, `ConstructUsing`, DI services and runtime lambda configuration remain runtime-only. Generated resolver registration is described below; invalid static method requests produce `MERIDIANGEN006`.

## Scalar conversions and null policies

Structural mode automatically supports C# implicit numeric widening, nullable value transitions, enum-to-numeric widening, and integral/enum-to-enum checked casts. Narrowing scalar numeric conversions require `[ConvertMapMember("Value", GeneratedConversionKind.CheckedNumeric)]`. String-to-number, character, DateTime and enum conversions require `GeneratedConversionKind.InvariantParse`; implicit parsing is never enabled. Unsupported combinations are diagnosed. These explicit attributes apply in either mode, compose with `MapMember`, and have the same paired selectors as other member attributes; combining `MapWith` or `IgnoreMapMember` with a conversion is invalid. Unconfigured Legacy int-to-long remains skipped with Info.

Generated casts follow C# checked conversion semantics: integral/decimal range violations throw `OverflowException`; floating-point-to-floating-point casts can produce infinity rather than throw. Fractional casts truncate (1.9 to int becomes 1), while the current runtime `Convert.ChangeType` rounds (1.9 becomes 2). Numeric/date parsing passes `InvariantCulture`; existing runtime parsing uses current culture. For example, under tr-TR, decimal text `"1.5"` maps to 1.5 in generated code and 15 at runtime. These are explicit opt-in differences, not runtime defaults being changed. Date parsing currently covers DateTime only; DateOnly, TimeOnly and DateTimeOffset remain unsupported. Character parsing uses the culture-independent single-character parser. Invalid numeric/date text preserves `FormatException` and out-of-range integral text preserves `OverflowException` on the tested intersection.

Structural enums are validated, including identity assignments. Without `AllowUndefinedEnumValues`, non-flags values must equal a declared value and flags values may contain only declared bits (zero is valid for flags even without a named zero). Parse failures and undefined values throw `MeridianEnumMappingException` with source value, destination enum type and destination member. Parsing ignores case using the enum parser's ordinal behavior; Turkish dotted-I is not treated as ASCII I. `AllowUndefinedEnumValues=true` permits numeric undefined values but does not make invalid text parseable. Existing runtime numeric-to-enum and same-enum assignment can permit undefined values; generated strictness is a deliberate Structural policy difference. Generated code uses statically typed casts, Enum.TryParse and emitted enum constants/bit masks, with no custom reflection or DynamicInvoke.

Null value sources produce the destination default (zero for nonnullable numbers, null for nullable values); nullable helpers read the source once. Root null still returns default. With `AllowNullDestinationValues=true`, null references are assigned, including to nonnullable annotated destinations without inventing instances. In Structural mode, false skips null ordinary reference setters and preserves the constructed destination value. The value is evaluated once and a skipped setter is not invoked. Potentially null init-only or required reference assignments receive `MERIDIANGEN005`, because conditional omission cannot preserve their construction semantics. Constructor arguments remain construction inputs and may receive null; a consumed initializer is not rejected or written twice, including `SetsRequiredMembers` cases. Legacy keeps its ordinary null policy unchanged; explicit conversions still implement their requested scalar conversion.

Differential tests cover int-to-long, nullable defaults, invariant DateTime text, enum names/undefined opt-out, and numeric/date parse exception types. Dedicated tests cover the deliberate culture, fractional-cast and numeric-enum differences. Existing runtime conversion and Turkish-culture fixtures remain part of verification.

## Nested graphs, collections and operation options

Declare every traversed source/destination object pair in the same container. Structural members use that pair even for same-type objects; ordinary same-type references without a declared pair remain shallow. Nested calls share one container-private `GeneratedMappingContext`, carrying Depth, effective MaxDepth/MaxCollectionItems, CancellationToken, State and a lazily allocated reference cache. The one-argument method delegates to the options overload. `GeneratedMappingOptions` is a core sealed record: nullable positive `MaxDepth`/`MaxCollectionItems` inherit the entry pair's attribute defaults, the token defaults to none, and `State` defaults to null. Validation and cancellation precede root-null handling. Direct calls carry opaque State; resolver calls share runtime Items/State through the operation context.

Root mapping begins at depth zero. A nested object consumes one depth; collection traversal adds a level for its elements. At `Depth >= MaxDepth`, the destination default returns before the reference cache is consulted. The entry pair's effective caps govern the entire generated operation, including nested pairs with different attribute defaults. Runtime per-map depth overrides and global collection policies retain their existing behavior; generated operation overrides do not alter them.

Supported destinations are one-dimensional arrays, List, IEnumerable, IList, ICollection, IReadOnlyList, IReadOnlyCollection, Dictionary, IDictionary and IReadOnlyDictionary. Sources must expose a statically known generic enumerable element type; dictionary sources enumerate KeyValuePair values. Collection element/key/value conversions use the supported scalar rules or declared nested pairs. New collections are materialized, and dictionary converted-key collisions use last assignment wins. Counted inputs are checked before allocating collection storage; streaming inputs are checked before mapping the first oversized item. `MeridianMappingLimitException` reports MaxCollectionItems, the effective cap, observed count and static collection types. Enumeration checks cancellation before acquisition/MoveNext and after yielded items, and disposes acquired enumerators on completion, cancellation or limit exceptions. A single blocking MoveNext remains the enumerable's responsibility. Null collections become empty by default or null with `AllowNullCollections=true`; Legacy keeps its original shallow aliases and nulls. Custom/immutable destination collections, multidimensional arrays and unknown enumerable shapes are diagnosed.

`PreserveReferences=true` on a declared pair caches reference-type source/destination mappings by source reference identity plus destination type, never value equality. Cache state is isolated per entry call; value-type mappings are not reference cached. Mutable objects enter the cache after constructor/required/init inputs and before ordinary setter traversal. Cycles whose recursive edge needs a constructor, init-only or required member before caching report `MERIDIANGEN005`; a required scalar on an otherwise mutable cycle is supported. Noncyclic immutable DTOs remain supported. Collections are newly materialized per mapped collection member; their object elements participate in declared-pair reference preservation, but collection-container aliases are not preserved. Unsupported nested pairs invalidate their callers with an actionable diagnostic. Generated helper identifiers `GeneratedMappingContext` and `__MeridianMap*` are reserved within structural containers.

## Diagnostics

All pair diagnostics point to the original `GenerateMapper` attribute, including attributes in separate partial declarations. `MERIDIANGEN001` retains its container identifier location. Current syntax trees are retained for diagnostics independently of the immutable generation model, preserving `#line`, pragma and suppression behavior across incremental edits.

| ID | Meaning | Severity |
| --- | --- | --- |
| `MERIDIANGEN001` | A containing type of a nested mapper is not partial. | Warning, unchanged |
| `MERIDIANGEN002` | Destination property has no eligible same-name source property, or property types differ. | Info in Legacy; Error in Structural |
| `MERIDIANGEN003` | Destination cannot be constructed with the currently supported constructor contract. | Error |
| `MERIDIANGEN004` | Duplicate pair, generated method collision, or collision with a declared container member/name. | Error |
| `MERIDIANGEN005` | Requested structural shape or generated capability is unsupported, including reference-preserved pre-cache cycles. | Error |
| `MERIDIANGEN006` | Invalid mode/limits/names/types, insufficient signature visibility, invalid selectors, conflicting member configuration or invalid static converter. | Error |

Legacy informational diagnostics do not become build failures under `TreatWarningsAsErrors=true`. Compiler errors already present in user source remain compiler errors. A pair with an error emits no mapping method; other valid pairs in that container remain available. A nested mapper with a non-partial containing type emits no mapper file. No error path emits a conflicting or knowingly invalid method.

## Verification boundaries

Tests compile and invoke generated sources for legacy aliases, strict scalar mapping, positional records, required/init properties, constructor resolution/defaults, renames, ignores, static methods, selected pairs, nested objects, collection limits/cancellation, cycle/diamond identity, depth boundaries and incremental updates. Negative cases assert generator diagnostics and the absence of generated compiler errors. Packaged consumer verification uses the existing C# 12 lanes on SDK 8.0.421, 9.0.318 and 10.0.300, while the production analyzer retains its Roslyn 4.8 / netstandard2.0 floor. These checks establish the supported subset; they do not establish trim/AOT compatibility for future structural features or full runtime mapping equivalence.


## Registering generated mappings with IMapper

Set `GenerateResolver=true` on each pair to expose through `new MyMaps.GeneratedResolver()`, then call `configuration.UseGeneratedMappings(...)`. The companion implements `IGeneratedMappingResolver` and optional `IGeneratedMappingDescriptorCatalog`; its immutable descriptor inventory allows eager overlap validation. Call `AssertConfigurationIsValid()` to reject all catalogued pairs claimed by multiple registered resolvers, including an opaque resolver overlapping a catalog. An opaque custom resolver exposes no finite inventory: pairs that no catalog advertises are checked against every resolver at lookup, and ambiguity throws before executing any descriptor. Resolver lookup must be stable and side-effect free. A successful resolver must return a nonnull descriptor for exactly the requested types.

Existing interfaces gain no abstract members. `IGeneratedMappingConfiguration` and `IGeneratedMappingConfigurationProvider` are optional capabilities; registration on an unsupported custom configuration throws `NotSupportedException`. Configuration snapshots registration, and descriptors fill only create-new operations lacking an explicit runtime TypeMap. Runtime source maps and declared/base/included TypeMaps take precedence. Map-to-existing and destination reuse retain runtime behavior. An explicit nested TypeMap also takes precedence inside Structural generated traversal, including its actions, services, global transformers and most-specific derived map. Generated traversal does not parse runtime profiles or run DI actions for unconfigured pairs. Legacy resolvers keep shallow member aliases and assignment semantics.

ResolutionContext forwards the same Items, State, service scope, reference cache and current depth. Its additive `TryMapConfigured` method uses the original Meridian Mapper engine, advancing by a validated relative depth; custom IMapper implementations receive `NotSupportedException` rather than a new operation with silently reset context. Optional limits only tighten the effective operation boundary. Read-only `MaxDepth`/`MaxCollectionItems` expose inherited effective limits to custom descriptors; custom descriptor implementations remain responsible for enforcing their own traversal. Companion resolvers take the minimum of attribute and effective runtime limits, and carry it through generated→runtime→generated traversal. Runtime per-map depth overrides retain their original behavior outside the generated bridge. Generated entry methods keep attribute/default or explicit GeneratedMappingOptions behavior; runtime State is opaque and is never interpreted as a way to raise limits.

Structural resolver calls use runtime `AllowNullCollections` for traversed collection members and runtime `AllowNullDestinationValues` for ordinary reference setters. Constructor arguments remain generated construction inputs and may be null. If false null-destination policy would require omitting an init-only or required reference assignment anywhere in the statically reachable generated graph, the selected descriptor throws `NotSupportedException` before source getters or construction. This guard is conservative even when a nested runtime TypeMap would replace that generated child; configure the root pair explicitly for that policy. Explicit root TypeMaps always win before the guard. Direct generated methods keep their documented construction behavior. Structural scalar conversion/enum policies remain the declared generated policies, including documented differences from runtime conversion; registration does not promise full profile equivalence.

`GeneratedResolver`, `GeneratedMappingContext` and `__MeridianMap*` are reserved where their companion/helpers are emitted. Direct generated calls remain independent of registration. The packaged `Meridian.GeneratedOnlyConsumer` exercises direct typed Structural methods, bounded collections, cycles, depth and cancellation under trimming and Native AOT; it intentionally does not instantiate the companion or runtime MapperConfiguration. Those runtime bridge/configuration/reflection paths are outside this AOT claim. `eng/run-aot-smoke.ps1 -MappingOnly` verifies an already packed candidate, pins the requested SDK and exact local NuGet package, publishes and executes the native binary, and records fixture/package/binary hashes. It fails on publish or execution errors and does not repack the candidate.


Registered exact same-type/assignable member pairs participate in create-new runtime parent mapping, including eligible compiled parents. Explicit TypeMaps take precedence, and per-member descriptors keep the current depth, services, Items/State and shared cache. Unregistered assignable values remain shallow aliases. An assignable collection stays shallow when only its element pair is registered; registering the collection's exact source/destination pair selects that descriptor, or a nonassignable collection conversion traverses its elements through the normal mapping path. Existing-destination and UseDestinationValue paths preserve the previous assignable-member behavior and do not opt into this create-new descriptor dispatch.

Assignable member dispatch preserves the declared getter type (the property, the terminal property in a flattened chain, or the MapFrom expression result). Runtime exact and declared/base/included explicit TypeMaps are resolved before any descriptor. If no explicit map applies, the runtime descriptor pair is tried first and the declared pair is the fallback. Compiled parents preserve the same declared type, including an interface expression whose actual value is assignable to the destination. Resolver/converter/function outputs, constants and null substitutes use their actual value type when no trustworthy selected-getter metadata exists; the bridge does not infer a base map from a different source property's metadata. This does not change nonassignable conversion ordering or existing-destination behavior.
