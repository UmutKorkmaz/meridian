# Mediator AOT and Diagnostics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Add verified generated mediator dispatch, actionable explicit-input diagnostics and optional bounded metrics.
**Architecture:** A separate analyzer emits closed wrappers and registrations through an additive registry interface. Strict generated mode rejects unsupported types; existing runtime registration remains supported.
**Tech Stack:** C#/.NET 8/9/10, Roslyn netstandard2.0, Microsoft.Extensions.DependencyInjection, System.Diagnostics.Metrics/Activity, Native AOT, xUnit.
**Spec:** [D design](../specs/2026-10-02-mediator-design.md) and the portfolio design.

## Global Constraints

- Keep existing APIs operational during documented deprecation windows; use additive replacements and reserve removals/default flips for a major release.
- Preserve runtime mapping defaults: DefaultMaxDepth=64, DefaultMaxCollectionItems=10000, AllowNullCollections=false, AllowNullDestinationValues=true, AllowUndefinedEnumValues=false.
- Preserve telemetry defaults: RecordExceptionMessage=false and RecordExceptionStackTrace=false; default notification publication remains sequential and concurrent publisher defaults remain capped at 16.
- Preserve existing generated method names and legacy assignment semantics; structural generation requires explicit opt-in.
- Core libraries continue targeting net8.0;net9.0;net10.0; generators target netstandard2.0; net11.0 preview coverage remains optional and non-blocking.
- Do not introduce FluentValidation, EF Core, Redis, ASP.NET Core, or telemetry-exporter dependencies into either core package.
- Preserve the reviewed dirty working tree; never reset, clean, stash, stage unrelated changes, or assume a worktree from HEAD includes the baseline.
- Publishing, tags, releases, external database changes, and new recurring monitors require explicit user authorization.
- Graph-Loop and Sol Advisor remain disabled; no workflow, custom agent, hook, or completion gate from either framework may be activated.

## Review Focus

- Generated registration without rooted closed dispatch falsely appearing AOT-safe — D2/D4.
- Open behavior constraints and standard validator registration applying twice or to invalid requests — D2.
- Two registries sharing notifications while duplicate request/stream handlers remain errors — D1/D3.
- Deferred stream execution/disposal losing request scope — D3.
- Metric cardinality/privacy and no-listener hot-path allocations — D5.

The two native commands run in their matching OS/architecture lanes, not consecutively on one machine. Default Consumer=Meridian.NativeAotConsumer preserves D4's short command; the mapping-only option was introduced by B6. Pass means zero failed self-checks, no mandatory skips, and no unexpected warnings in the claimed configuration. The metrics type budget is 100 admitted names plus one overflow bucket, hence at most 101 total.
