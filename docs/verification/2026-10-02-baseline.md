## Stable CI and preview isolation

`ci.yml` has nine required lanes: each combination of Ubuntu/Windows/macOS and
net8.0/net9.0/net10.0. Every stable lane installs SDK/runtime families 8, 9, and
10, verifies they exist, selects a stable .NET 10 SDK, builds the solution, and
runs its test projects with the explicit runtime target. `LatestPatch` prevents
runtime-family roll-forward. `global.json` permits stable .NET 10 feature-band
updates and rejects prerelease SDKs. Native SDK 8/9 consumers need separate
compatibility verification; installing those SDKs here is runtime provisioning.

The independent `preview samples (net11.0, optional)` job installs SDK 11,
selects it only in its own checkout, enables `MeridianIncludeNet11Samples=true`,
and has job-level `continue-on-error: true`. Stable jobs have no dependency on
that job. Preview SDK/sample failures are optional. Its check name must not be
required by branch protection.
