Meridian

A lightweight toolset for .NET applications — Meridian.Mediator for CQRS-style in-process messaging and Meridian.Mapping for object mapping with safe-by-default limits.

View on GitHub NuGet · Mediator NuGet · Mapping

Packages

Meridian.Mediator

Requests, notifications, streams, pipeline behaviors, and focused abstractions (ISender, IPublisher, IStreamSender).

Meridian.Mapping

Profiles, resolvers, converters, query projection and a bundled source generator, with depth and collection caps on by default.

Quick start

services.AddMeridianMediator(cfg =>
{
    cfg.RegisterServicesFromAssemblyContaining<Program>();
});
